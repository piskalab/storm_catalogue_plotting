# Storm catalogue plotting

## Credentials

EarthCARE access API keys and tokens are stored in a `credentials.txt` file.

### Creating `credentials.txt`
1. Create a plain text file called `credentials.txt`.
2. Copy the following text into the file, replacing `your_earthcare_longlasting_token_here` with your actual token. You can generate a long-lasting token here: https://portal.maap.eo.esa.int/ini/services/auth/token/90dToken.php:
```
CLIENT_ID=offline-token
CLIENT_SECRET=p1eL7uonXs6MDxtGbgKdPVRAmnGxHpVE
OFFLINE_TOKEN=your_earthcare_longlasting_token_here
```
